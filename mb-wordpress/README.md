# MB - Мультиплатформенный музыкальный проект

Проект музыкального сервиса, включающий HTML-шаблон и WordPress-тему. Реализован для демонстрации процесса конвертации статического HTML-шаблона в полноценную WordPress тему с сохранением дизайна и функциональности.

## О проекте

Проект включает две основные части:
1. **HTML-шаблон (mb-html)** - статическая версия сайта, разработанная с использованием Gulp, SCSS, Nunjucks и JavaScript
2. **WordPress-тема (mb-wp-theme)** - полноценная WordPress-тема, созданная на основе HTML-шаблона с использованием фреймворка _s (Underscores)

Демонстрирует процесс перехода от статической верстки к динамическому сайту на WordPress с сохранением оригинального дизайна и функциональности.

## Моя роль

- Fullstack-разработка (Frontend + WordPress)
- Создание модульной архитектуры шаблонов с Nunjucks
- Разработка адаптивного дизайна с SCSS
- Интеграция HTML-шаблона с WordPress
- Настройка системы сборки на Gulp

## Технологии

### HTML-шаблон (mb-html)
- HTML5 с шаблонизатором Nunjucks
- SCSS для стилизации
- JavaScript (ES6+)
- Gulp для автоматизации сборки
- Адаптивный дизайн

### WordPress-тема (mb-wp-theme)
- WordPress 5.0+
- PHP 7.4+ для интеграции с WordPress
- _s (Underscores) как фреймворк для темы
- Кастомные шаблоны страниц
- Интеграция с исходными стилями и скриптами

## Структура проекта

```
mb-wordpress/
├── mb-html/                # HTML-шаблон
│   ├── src/                # Исходные файлы
│   │   ├── templates/      # Nunjucks шаблоны
│   │   ├── scss/           # SCSS стили
│   │   ├── js/             # JavaScript файлы
│   │   └── img/            # Изображения
│   ├── public/             # Скомпилированные файлы
│   ├── gulpfile.js         # Конфигурация Gulp
│   └── package.json        # Зависимости проекта
│
└── mb-wp-theme/            # WordPress-тема
    └── mubicloud/          # Основная тема
        ├── src/            # Исходные файлы
        ├── inc/            # Дополнительные функции
        ├── template-parts/  # Части шаблонов
        ├── page-templates/  # Шаблоны страниц
        ├── functions.php   # Основной файл функций
        └── style.css       # Стилевой файл темы
```

## Особенности реализации

- Модульная архитектура с повторно используемыми компонентами
- Адаптивный дизайн для всех устройств
- Оптимизация изображений и ресурсов
- Подключение скриптов и стилей через стандартные функции WordPress
- Кастомные шаблоны страниц для различных разделов сайта
- Продвинутая система сборки для автоматизации разработки

## Команды для разработки

### HTML-шаблон
- `npm install` - установка зависимостей
- `gulp` - запуск сборки и отслеживания изменений

### WordPress-тема
- `npm install` - установка зависимостей
- `gulp` - сборка ресурсов для темы
