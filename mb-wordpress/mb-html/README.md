# MB HTML - Музыкальный портал (HTML-шаблон)

HTML-шаблон музыкального портала с интерактивными элементами, адаптивным дизайном и модульной архитектурой. Создан с использованием современных технологий для frontend-разработки.

## О проекте

Статический шаблон музыкального портала, разработанный с модульной архитектурой на базе Nunjucks и современных инструментов frontend-разработки. Включает полный набор страниц, интерактивные элементы и адаптивный дизайн.

## Технологии

- HTML5 с шаблонизатором Nunjucks для модульности
- SCSS с компонентной структурой
- JavaScript (ES6+)
- Gulp 4 для автоматизации процессов разработки
- PostCSS для оптимизации CSS (autoprefixer, cssnano)
- BrowserSync для live-reload разработки

## Структура проекта

```
/
├── src/                # Исходные файлы
│   ├── templates/      # Nunjucks шаблоны
│   │   ├── layout/     # Макеты страниц
│   │   └── partials/   # Компоненты шаблонов
│   ├── scss/           # SCSS стили
│   │   └── _includes/  # Компоненты стилей
│   ├── js/             # JavaScript файлы
│   │   └── _includes/  # JavaScript модули
│   ├── img/            # Изображения
│   └── fonts/          # Шрифты
├── public/             # Скомпилированные файлы
├── gulpfile.js         # Конфигурация Gulp
└── package.json        # Зависимости проекта
```

## Особенности реализации

- Модульная структура Nunjucks шаблонов для повторного использования компонентов
- Адаптивный дизайн с поддержкой мобильных устройств
- Оптимизация производительности с использованием cssnano и uglify
- Генерация карты сайта при сборке
- Автоматическое обновление кеша для предотвращения проблем с кешированием

## Установка и запуск

### Требования
- Node.js 8.11+
- npm/yarn

### Установка
```
npm install
```

### Разработка
```
npx gulp
```

Запускает сборку проекта и отслеживание изменений с автоматическим обновлением браузера.

### Команды Gulp

- `gulp` - запуск полного цикла разработки (сборка + отслеживание изменений)
- Отдельные задачи:
  - `scssTask` - компиляция SCSS в CSS
  - `jsTask` - сборка и минификация JavaScript
  - `htmlTask` - компиляция Nunjucks шаблонов
  - `imgTask` - копирование и оптимизация изображений
