# MB WordPress - Музыкальный портал (WordPress-тема)

WordPress-тема музыкального портала, основанная на _s (Underscores) с кастомными шаблонами страниц и модульной структурой. Реализована как WordPress-версия оригинального HTML-шаблона.

## О проекте

Полнофункциональная WordPress-тема для музыкального портала, сохраняющая оригинальный дизайн и функциональность HTML-шаблона. Разработана на основе стартового фреймворка _s (Underscores) с адаптацией структуры и подходов к WordPress-разработке.

## Технологии

- WordPress 5.0+
- PHP 7.4+ для интеграции с WordPress и кастомных шаблонов
- _s (Underscores) как фреймворк для WordPress-темы
- SCSS для стилей (адаптированы из HTML-шаблона)
- JavaScript для интерактивных элементов
- Gulp для сборки ресурсов

## Структура проекта

```
/
├── inc/                    # Компоненты WordPress
│   ├── customizer.php      # Настройки кастомайзера
│   ├── template-tags.php   # Пользовательские теги шаблонов
│   └── template-functions.php # Вспомогательные функции
├── template-parts/         # Части шаблонов
│   └── content/            # Типы содержимого
├── page-templates/         # Кастомные шаблоны страниц
├── src/                    # Исходные файлы
│   ├── sass-wp-undescores/ # SCSS для базовой темы
│   ├── scss/               # SCSS из HTML-шаблона
│   ├── js/                 # JavaScript файлы
│   └── img/                # Изображения
├── languages/              # Файлы локализации
├── functions.php           # Основной файл функций
└── style.css               # Информация о теме
```

## Особенности реализации

- Адаптация HTML-шаблона к структуре WordPress-темы
- Кастомные шаблоны страниц для различных разделов сайта
- Интеграция стилей и скриптов через стандартные хуки WordPress
- Поддержка мультиязычности
- Оптимизация изображений и ресурсов
- Соблюдение стандартов кода WordPress

## Установка и разработка

### Требования
- WordPress 5.0+
- PHP 7.4+
- Node.js 8.11+
- npm/yarn

### Установка
1. Установить тему в директорию `wp-content/themes/`
2. Активировать тему через админ-панель WordPress
3. Для разработки, выполнить:
```
npm install
```

### Команды разработки
- `gulp` - запуск сборки и отслеживания изменений
- `composer lint:wpcs` - проверка соответствия стандартам кода WordPress
- `composer lint:php` - проверка синтаксиса PHP
- `composer make-pot` - генерация файлов локализации
