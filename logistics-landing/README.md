# Logistics Landing - WordPress Sage Theme

WordPress-тема для лендинга логистической компании, специализирующейся на доставке для маркетплейсов. Разработана на основе фреймворка Sage с использованием Laravel Blade для шаблонизации и Bud.js для сборки ресурсов.

## О проекте

Одностраничный адаптивный лендинг с интерактивными элементами, системой табов для тарифов и слайдерами. Построен на архитектуре Sage с Laravel Blade для шаблонизации и модульной организации кода. Использует современные подходы к разработке и компонентную архитектуру.

## Моя роль

- Fullstack-разработка (PHP/WordPress + Frontend)
- Верстка адаптивного лендинга
- Интеграция JavaScript-функциональности (слайдеры, табы)
- Разработка компонентного подхода с Laravel Blade
- Оптимизация производительности и UX

## Технологии

- WordPress с фреймворком Sage
- PHP 8.2
- Laravel Blade для шаблонизации
- ES6+ JavaScript с компонентным подходом
- SCSS с модульной архитектурой
- Swiper.js для слайдеров
- Bud.js (Webpack) для сборки ресурсов

## Структура проекта

```
/
├── app/                  # PHP-код темы
│   ├── View/             # Контроллеры представлений 
│   ├── Providers/        # Сервис-провайдеры
│   ├── Options/          # Опции темы
│   ├── setup.php         # Настройки темы
│   └── filters.php       # Фильтры WordPress
├── resources/            # Исходные файлы
│   ├── scripts/          # JavaScript-файлы
│   │   └── filters/      # JS-фильтры
│   ├── styles/           # SCSS-файлы
│   │   ├── common/       # Общие стили
│   │   └── components/   # Компоненты UI
│   └── views/            # Шаблоны Blade
│       ├── components/   # Компоненты интерфейса
│       ├── sections/     # Секции лендинга
│       └── layouts/      # Макеты страниц
├── public/               # Собранные ресурсы
├── functions.php         # Основной файл темы
└── bud.config.js         # Конфигурация сборки
```

## Особенности реализации

- Компонентный подход к разработке интерфейса
- Модульная JavaScript-архитектура
- Интерактивные элементы (слайдеры, табы)
- Mobile-first адаптивный дизайн
- Оптимизация производительности и загрузки
- Семантическая разметка для SEO

## Команды для разработки

- `yarn dev` - режим разработки с автоперезагрузкой
- `yarn build` - сборка для продакшена
