# Corporate Business - WordPress Theme

WordPress-тема для корпоративного бизнес-сайта с адаптивным дизайном и кастомизируемыми секциями. Разработана на базе фреймворка Underscores с использованием современных подходов к верстке и организации кода.

## О проекте

Полнофункциональная тема WordPress для корпоративных сайтов с чистой архитектурой кода, семантической разметкой и модульной организацией стилей. Тема включает кастомные шаблоны страниц, поддержку произвольных полей ACF и оптимизацию для SEO и производительности.

## Моя роль

- Fullstack-разработка (PHP/WordPress + Frontend)
- Создание кастомных шаблонов страниц и модульных компонентов
- Верстка адаптивного интерфейса с SASS/SCSS
- Интеграция с WordPress и ACF
- Оптимизация для SEO и производительности

## Технологии

- WordPress 6.0+
- PHP 7.4+ для интеграции с WordPress
- HTML5/CSS3 с SASS препроцессором
- Vanilla JavaScript для интерактивных элементов
- Mobile-first адаптивный подход
- Интеграция с ACF для гибкого управления контентом
- Node.js для сборки и оптимизации ресурсов

## Структура проекта

```
/
├── sass/                # SCSS исходники
```

## Особенности реализации

- Структурированная архитектура SASS по методологии 7-1
- Семантическая HTML5 разметка для SEO-оптимизации
- Адаптивный дизайн с mobile-first подходом
- Оптимизированная загрузка стилей и скриптов
- Расширенные кастомные шаблоны для страниц
- Интеграция с ACF для гибкого управления контентом
- Поддержка мультиязычности и RTL

## Команды для разработки

- `npm run watch` - компиляция SASS с отслеживанием изменений
- `npm run compile:css` - компиляция SASS и применение линтера
- `npm run compile:rtl` - создание RTL-версии стилей

## Установка и запуск

1. Скачайте и установите WordPress
2. Скопируйте папку темы в `/wp-content/themes/`
3. Активируйте тему в административной панели WordPress
4. Установите плагин Advanced Custom Fields (рекомендуется)
5. Импортируйте настройки полей ACF (если доступны)

### Для разработки

```bash
# Установка зависимостей
npm install

# Компиляция SASS с отслеживанием изменений
npm run watch

# Компиляция стилей для продакшена
npm run compile:css
```
