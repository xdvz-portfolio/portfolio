# Портфолио

Production-проекты на WordPress/WooCommerce в активной эксплуатации. Представлены в виде демо-версий с сохранением всей архитектуры и технических решений. Конфиденциальная бизнес-логика заменена на типовые реализации.


## Проекты

### 1. RShop — Интернет-магазин на WooCommerce
![WordPress](https://img.shields.io/badge/WordPress-5.8+-blue.svg) ![PHP](https://img.shields.io/badge/PHP-8.0+-green.svg) ![Vite](https://img.shields.io/badge/Vite-5-orange.svg) ![React](https://img.shields.io/badge/React-18-blue.svg)

Дочерняя тема с кастомными шаблонами, хуками и фильтрами. Используется Vite для сборки и ускоренной разработки.

**Что реализовано:**
- Глубокая кастомизация WooCommerce
- JS/CSS как модули
- Оптимизация фронта и UX
- Hot Reload через Vite

[Подробнее о проекте](./rshop)

- **Vite**, **Laravel Mix**, **Gulp**, **Bud.js**, **WebPack**

- **Git**, **Nunjucks**, **ACF**, адаптив, SEO
