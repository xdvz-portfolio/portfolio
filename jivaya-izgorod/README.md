# Живая Изгородь - WordPress Лендинг

WordPress-тема для лендинга компании по созданию живых изгородей. Основана на фреймворке Sage 10 с шаблонизатором Laravel Blade и сборщиком Bud.js.

## О проекте

Одностраничный лендинг на WordPress с современной архитектурой Sage 10, использующей Laravel Blade для создания шаблонов. Включает адаптивный дизайн, оптимизированную производительность, современный процесс сборки на основе Bud.js и строгую компонентную архитектуру.

## Моя роль

- Fullstack-разработка (PHP/WordPress + Frontend)
- Создание компонентной структуры с использованием Laravel Blade
- Верстка адаптивного макета на основе SCSS
- Реализация JavaScript-функциональности
- Интеграция с WordPress и настройка темы

## Технологии

- WordPress 5.9+
- PHP 7.4+ с архитектурой Sage 10
- Laravel Blade для шаблонизации
- ES6+ JavaScript
- SCSS с компонентной структурой
- Bud.js (Webpack) для сборки
- SmoothScroll для улучшения UX

## Структура проекта

```
/
├── app/                 # PHP-код темы
│   ├── View/            # Контроллеры представлений
│   ├── Providers/       # Сервис-провайдеры
│   ├── setup.php        # Настройки темы
│   └── filters.php      # Фильтры WordPress
├── resources/           # Исходные файлы
│   ├── scripts/         # JavaScript-файлы
│   ├── styles/          # SCSS-файлы
│   │   └── sass/        # Структурированный SCSS
│   ├── views/           # Шаблоны Blade
│   │   ├── components/  # Компоненты UI
│   │   ├── layouts/     # Макеты страниц
│   │   └── sections/    # Секции лендинга
│   └── images/          # Изображения
├── public/              # Собранные ресурсы
├── functions.php        # Основной файл темы
└── bud.config.mjs       # Конфигурация сборщика
```

## Особенности реализации

- Компонентная структура UI с изолированными шаблонами
- Оптимизация загрузки скриптов и стилей
- Использование Laravel Blade для модульных шаблонов
- Адаптивный дизайн для всех типов устройств
- Реализация плавного скроллинга

## Команды для разработки

- `yarn dev` - режим разработки с автоперезагрузкой
- `yarn build` - сборка для продакшена
