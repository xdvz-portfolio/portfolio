rshop Theme Development Server

Внимание: Это страница сервера разработки Vite. Для работы над WordPress темой необходимо:

  1. Открыть http://rshop.local - ваш сайт на WordPress.
  2. Добавить интеграцию с Vite в файл functions.php.
  3. Поддерживать сервер Vite работающим для горячей замены модулей (HMR).

Как это работает

Когда сервер Vite запущен:

  • Изменения в SCSS автоматически обновляют стили без перезагрузки.
  • Изменения в JS файлах также применяются мгновенно.
  • Результат сборки сохраняется в папке dist/ следующим образом:
    • dist/build.css - скомпилированные стили
    • dist/build.js - скомпилированный JavaScript

Интеграция с WordPress

Файл vite-integration.php содержит все необходимые функции для интеграции с WordPress.

Более подробная информация представлена в файле README.md.
