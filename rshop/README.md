# RShop - WordPress WooCommerce

Дочерняя тема WordPress для интернет-магазина на базе WooCommerce. Включает кастомизированные шаблоны, специализированные функции PHP и оптимизированный frontend с использованием Vite.

## О проекте

Дочерняя тема для Storefront с кастомизированными шаблонами WooCommerce, дополнительными хуками и функциями. Использует процесс сборки на базе Vite для оптимизации frontend-ресурсов и компонентный подход к разработке.

## Моя роль

- Fullstack-разработка (PHP/WordPress + Frontend)
- Настройка кастомных хуков и фильтров WooCommerce
- Оптимизация производительности WordPress
- Настройка системы сборки и деплоя
- Настройка сервера Ubuntu, nginx, PHP-FPM, MySQL(MariaDB), Redis
- Оптимизация ресурсов сервера для выгрузки товаров
- Настройка Workflow выгрузки для клиента через Cron.
- Разработка небольших плагинов для SEO, оплаты и доставки в Woocommerce.


## Технологии

- WordPress 5.8+ / WooCommerce 6.0+
- PHP 8.0+ (хуки, фильтры, кастомные функции)
- ES6+ с поддержкой React
- SCSS с компонентной архитектурой
- Vite 5 
- Swiper
- Git 

## Структура проекта

```
/
├── src/                  # Исходный код фронтенда 
│   ├── js/               # JavaScript, включая React
│   ├── scss/             # Стили с компонентным подходом
│   └── assets/           # Статические ресурсы
├── inc/                  # PHP-компоненты и кастомные функции
├── woocommerce/          # Переопределенные шаблоны WooCommerce
├── functions.php         # Основной функциональный файл
└── style.css             # Файл регистрации темы WordPress
```

## Особенности реализации

- Кастомные хуки и фильтры для WooCommerce
- Система сборки на Vite с интеграцией в WordPress
- Компонентная архитектура JavaScript и CSS
- Оптимизация производительности при загрузке изображений, скриптов и стилей
- Интеграция React-компонентов в стандартный WordPress
- Деплой через GitHub Actions


## Команды для разработки

- `npm run dev` - режим разработки
- `npm run build` - сборка для продакшена
- `npm run quick-deploy` - обновление версии и деплой
