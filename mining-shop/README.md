# Mining Equipment Store - WordPress Theme

WordPress-тема для интернет-магазина майнингового оборудования. Основана на архитектуре Sage с использованием Laravel Blade для шаблонизации и Laravel Mix для сборки ассетов.

## О проекте

Полноценная тема WordPress с собственными типами постов для каталога и системой отзывов. Интегрирует компоненты интерфейса на основе Bootstrap 5 с SCSS-стилизацией и JavaScript-функциональностью. Использует Laravel Blade для шаблонов и эффективной модульной структуры представлений.

## Моя роль

- Fullstack-разработка (PHP/WordPress + Frontend)
- Создание и интеграция кастомных типов постов и таксономий
- Разработка шаблонов с использованием Laravel Blade
- Настройка сборки фронтенд-ресурсов через Laravel Mix
- Реализация JavaScript-функциональности и React-компонентов

## Технологии

- PHP 7.2+ с архитектурой на основе Sage/Roots
- WordPress в качестве основной CMS
- Laravel Blade для шаблонизации
- SCSS с компонентной архитектурой
- JavaScript ES6+ с поддержкой React
- Laravel Mix/Webpack для сборки ресурсов
- Bootstrap 5 для базовых компонентов UI

## Структура проекта

```
/
├── app/                 # PHP-код темы
│   ├── View/            # Контроллеры представлений
│   ├── Providers/       # Сервис-провайдеры
│   └── *.php            # Файлы настройки
├── resources/           # Исходные файлы
│   ├── assets/          # Frontend-ресурсы
│   │   ├── scripts/     # JavaScript-файлы
│   │   │   └── react-slider/   # React-компоненты
│   │   └── styles/      # SCSS-файлы
│   └── views/           # Шаблоны Blade
│       ├── components/  # Многоразовые компоненты
│       └── layouts/     # Макеты страниц
├── functions.php        # Основной файл темы
└── webpack.mix.js       # Конфигурация сборки
```

## Особенности реализации

- Компонентная архитектура для фронтенд-разработки
- Кастомные типы постов для каталога товаров и отзывов
- Интеграция React-компонентов с WordPress
- Оптимизация производительности с Laravel Mix
- Модульные шаблоны через Laravel Blade

## Команды для разработки

- `yarn start` - режим разработки с BrowserSync
- `yarn build` - сборка для разработки
- `yarn build:production` - сборка для продакшена
