# Демо Металлообработка

Адаптивный одностраничный лендинг для металлообрабатывающей компании. Проект в дальнейшем был интегрирован с CMS WordPress.

## О проекте

Адаптивный лендинг с минималистичным и современным дизайном, слайдером выполненных работ и готовой структурой для SEO-оптимизации. Верстка построена на fexbox.

## Моя роль

- Разработка дизайна и frontend-реализация
- Кроссбраузерная и адаптивная вёрстка
- Оптимизация производительности и загрузки ресурсов

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (flexbox, медиа-запросы, респонсивные единицы)
- JavaScript (ES6+)
- Slick Slider (для карусели работ)
- Font Awesome 6 (иконочный шрифт)
- Оптимизация для PageSpeed

## Структура проекта

```
/
├── index.html       # Главная страница
├── css/            
│   ├── style.css    # Основные стили
│   └── mobile.css   # Адаптивные стили для мобильных устройств
├── js/
│   └── main.js      # Скрипты сайта (слайдер, навигация)
├── img/             # Изображения и графика
└── files/           # Загружаемые файлы
```

## Особенности реализации

- Семантическая HTML-структура для лучшей SEO-оптимизации
- Модульная CSS-архитектура для удобной поддержки
- Адаптивный дизайн с брейкпоинтами под все стандартные устройства
- Оптимизированные изображения и lazy-loading
- Плавный скролл к разделам страницы с якорными ссылками
- Интерактивная галерея работ с автопрокруткой
- Встроенная интеграция с Google Maps
